# Muhammad Zeeshan — Academic Research Portfolio

This is the source of the personal research website at https://muhammad-zeeshan-2023.github.io/.

## Publish to GitHub Pages

Upload the **contents** of this folder, not the surrounding folder, to the root of the `Muhammad-Zeeshan-2023.github.io` repository's `main` branch. Replace the existing `index.html`. Keep GitHub Pages configured to publish from `main` / `(root)`.

### Files

- `index.html` — responsive academic website, including HTML, CSS, and JavaScript.
- `assets/Muhammad_Zeeshan_CV.pdf` — CV used by the Download CV links.
- `assets/images/` — upload your own project images here.

### Add project photos (no HTML changes needed)

1. Add a landscape photograph of your SCOUT MINI Pro project named **`scout-mini.jpg`** to `assets/images/`.
2. Add a landscape photograph of your GNSS-resilient UAV project named **`gnss-uav.jpg`** to `assets/images/`.
3. Push or commit the changes. The site uses the images automatically. Until then, built-in vector technical illustrations remain visible.

Recommended: landscape 16:9 or 3:2, 1200–1800 pixels wide, JPEG at ~200–500 KB each. Remove sensitive lab details and only publish images you have permission to share.
